# Pounce Game Assets

## Asset Structure

### Sprites
- `sprites/cat.png` - Cat player sprite (32x32)
- `sprites/pirate.png` - Pirate enemy sprite (32x32)

### Backgrounds
- `backgrounds/sea.png` - Tiled sea background (256x256)

### Textures
- `textures/island.png` - Island/territory texture

## Placeholder Assets

Current assets are simple placeholders:
- Cat: Orange emoji-style sprite
- Pirate: Dark emoji-style sprite
- Sea: Blue gradient background

## To Replace

Replace placeholder PNGs with professional sprite sheets:
- Use 32x32 or 64x64 sprites
- Create sprite sheets for animations
- Add multiple frames for walking
- Add directional sprites (up, down, left, right)

## Free Asset Sources

- Kenney.nl - Free game assets
- OpenGameArt.org - Community assets
- Itch.io - Free/paid sprite packs
